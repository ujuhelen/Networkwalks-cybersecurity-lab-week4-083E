# Networkwalks-cybersecurity-lab-week4-083E
Hands-on Networkwalks cybersecurity lab covering web reconnaissance, PDF metadata analysis, SQL backup exposure, vulnerability assessment, and security recommendations using Kali Linux.
Objectives

- Perform web reconnaissance.
- Analyse PDF metadata using ExifTool.
- Identify exposed SQL database backups.
- Assess security vulnerabilities.
- Recommend security improvements.

Tools Used

- Kali Linux
- Firefox
- ExifTool
- qpdf
- Linux command-line tools

Key Findings

- Sensitive information was exposed through a publicly accessible database backup.
- PDF metadata contained information about the backup location.
- Directory listing was enabled on the old backup directory.

Recommendations

- Remove exposed database backups from public web directories.
- Disable directory listing.
- Remove unnecessary metadata from PDF documents.
- Apply secure access controls and review web application security.
